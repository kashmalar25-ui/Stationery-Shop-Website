# Stationery Shop Website

## Overview

The **Stationery Shop Website** is a web-based project developed as part of the **Information and Communication Technology (ICT)** course at Air University. The purpose of this project was to design and develop a user-friendly website for a stationery business, allowing users to browse products and access business information through an interactive interface.

---

## Project Objectives

* Design a visually appealing and user-friendly website.
* Develop a structured and responsive web interface.
* Apply fundamental web development concepts.
* Improve user navigation and browsing experience.

---

* Home Page
